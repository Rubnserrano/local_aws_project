# Development Log - Plataforma de Datos Local

## 2026-04-23

### Fase 1: Sistema de colas (S3 → SQS)

#### Configuración de Infraestructura
- **Docker Compose**: LocalStack + ETL container
  - LocalStack emula S3, SQS, Lambda
  - Puerto 4566
- **Terraform**: Infra como código para LocalStack

#### Recursos creados
- **S3 Buckets**:
  - bronze-bucket-dev (raw data)
  - silver-bucket-dev (cleaned data)
  - gold-bucket-dev (analytics ready)
- **SQS**:
  - bronze-ingestion-queue + DLQ
- **S3 → SQS Notifications**:
  - Cuando se sube un archivo a bronze-bucket-dev, se envía mensaje a SQS

#### Código desarrollado
- `src/bronze/gluejob/ingestion.py`: Extrae datos de restcountries.com y guarda en S3 bronze
- `src/lambda/index.py`: Código de Lambda (no desplegable en LocalStack)

#### Limitaciones
- IAM roles no funcionan en LocalStack (InvalidClientTokenId)
- Lambda no desplegable (requiere IAM)
- Notifications solo en bucket bronze (por ARN inválido en silver/gold)

#### Cómo ejecutar
```bash
cd docker && docker compose up -d
python src/bronze/gluejob/ingestion.py  # desde contenedor o con endpoint http://localhost:4566
```

### Fase 2: Silver - Transformación
